- `profile-banner-mobile.svg`: narrow-screen variant selected by the README's `picture` element.

- `vsh-workflow-mobile.svg`: compact vertical variant of the same workflow, for narrow project cards.
- `buddybot.jpg`: unchanged copy of the real robot photo from [BuddyBot](https://github.com/rasasoe/BuddyBot/blob/main/docs/assets/portfolio/buddybot-hero-v2.jpg). Git blob SHA: `8c73f55526a1591e6304a5e36fb12dcb17f1a6cd`. No cropping, generated hardware, or reconstruction was applied.

Keep the SVGs self-contained and XML-valid. The README uses standard GitHub-supported HTML; custom page CSS is intentionally not required. Detailed project documentation and videos remain in their source repositories.
